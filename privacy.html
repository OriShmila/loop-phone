Loop — Privacy

Loop is a personal program run by its owner, Ori Shmila, on his own computer. This page says what it does with your data.

Where Loop runs

Loop runs on the owner's own Mac. Its record, its keys and its work stay there. There is no Loop server that collects anything.

Google Drive

When the owner connects Google, Loop asks only for drive.file: access to the files Loop itself creates. It cannot see, read or change any other file in the Drive. Loop uses it to keep an encrypted backup of its own record in a folder named "Loop".

The sign-in's tokens are kept in the Mac's Keychain. They are never shared, sold, or sent anywhere except to Google, to make the calls Loop needs.

Other accounts

Accounts the owner connects (such as GitHub or Anthropic) are used only for what the owner allowed, each call recorded in Loop's record on the owner's Mac.

Sharing and selling

Loop shares no data with anyone and sells nothing. Google user data is used only to provide Loop's backup to its owner, as Google's API Services User Data Policy requires, including its Limited Use requirements.

Removing access

The owner can disconnect Google in Loop at any time, or remove Loop's access at myaccount.google.com/permissions. The backup folder stays in the Drive until it is deleted there.
